What's in the Skeleton?

Everything you need to kickstart your next project

Shared Layout

Responsive header, navigation, and footer components with consistent styling across all pages.

Theme System

Light and dark themes with CSS custom properties. Theme preference persists across sessions.

Mock Authentication

Simulated login/logout with localStorage. No backend required for prototyping.

Data Layer

Simple localStorage abstraction for CRUD operations. Includes data validation and export/import.

Responsive Design

Mobile-first responsive layout that works seamlessly on all screen sizes.

Accessibility

WCAG 2.1 AA compliant with proper semantics, ARIA labels, and keyboard navigation.
